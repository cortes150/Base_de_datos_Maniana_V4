1. Crear la nueva rama y cambiarte a ella
Usa el comando git checkout con la opción -b:
bash

git checkout -b nombre-de-tu-rama
(También puedes usar el comando moderno git switch -c nombre-de-tu-rama).
2. Agregar los archivos al área de preparación (staging)
Prepara tus archivos modificados o nuevos:
bash

git add .
3. Hacer el primer commit
Guarda la instantánea de tus cambios con un mensaje descriptivo:
bash

git commit -m "primer commit en mi nueva rama"
4. Subir la rama a su propio espacio remoto
Envía la rama por primera vez al servidor remoto (como GitHub o GitLab) vinculándola con -u:
bash

git push -u origin nombre-de-tu-rama
